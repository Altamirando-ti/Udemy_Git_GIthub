pwd (Print Working Directory) - Pasta onde estou
cd (Change Directory)

rm (Remove) - Como apagar arquivos e pastas

rm -r diretório ou rm -f diretório  //Para apagar uma pasta (e seu conteúdo):

man comando
Man Pages (man): Se você esquecer o que um comando faz ou quiser saber todas as suas opções, digite man comando (por exemplo, man ls). Pressione q para sair da página do manual.

-----------Repositório Local------------
git status
git add .   //adicionar no Staging Area
git rm --cached -r .    //Remover do Staging Area
git commit -m "Texto explicativo do commit"
git log // para ver o histórico de commits 

----- outros comandos
git branch name-of-branch // cria um novo branch "ramificação"
git branch // visualiza as branches existentes
git checkout name-of-branch // trocar de branch
git merge name-of-branch // obs: precisa estar no branch principal que vai receber as modificações


-----------Repositório Remoto------------
git remote add origin <repository-URL-copiar HTTPS do Repositóriod do Github>
git push -u origin main 	ou 		git push origin main -u
git clone URL
